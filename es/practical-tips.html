Consejos prácticos

Da un ID a cada solicitud

Un formato simple como REQUEST-2026-001 basta para que el trabajo no viva solo en asuntos de e-mail y memoria.

Usa como máximo 6 estados

Nuevo, en revisión, esperando respuesta, oferta enviada, cerrado, bloqueado. Si hacen falta más, primero hay que aclarar el proceso.

Un responsable por cada asunto

La responsabilidad compartida a menudo acaba siendo falta de responsabilidad. Cada asunto activo debe tener una persona responsable actual.

No automatices un proceso confuso

Primero define entrada, estado y salida. Un mal proceso automatizado solo produce errores más rápido.

Usa plantillas para documentos recurrentes

Si un documento se produce varias veces al mes, debe tener una plantilla revisada y una lista de datos obligatorios.

Revisa los bloqueos una vez por semana

La lista de bloqueos suele decir más que un informe largo. Muestra dónde hace falta una decisión o un cambio de sistema.

¿Cuándo merece la pena pensar en software interno?

Si los mismos datos se introducen varias veces, si el estado de los asuntos no está claro, o si la operación diaria depende de la memoria de una persona, conviene planear un pequeño sistema interno.
