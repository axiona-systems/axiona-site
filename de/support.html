AXIONA SUPPORT

Hilfe für AXIONA Anwendungen und Systeme.

Wenn Sie eine Frage zur Nutzung haben, ein Problem feststellen, auf etwas nicht zugreifen können oder ein Sicherheitsproblem vermuten, sind Sie hier richtig. Support ist derzeit direkt per E-Mail erreichbar; ein technisches Ticket müssen Sie nicht vorbereiten.

01

Frage zur Nutzung

Wenn eine Funktion, ein Schritt oder ein Arbeitsablauf nicht klar ist, beschreiben Sie kurz, was Sie erreichen möchten und an welcher Stelle Sie nicht weiterkommen.

02

Fehler oder unerwartetes Verhalten

Beschreiben Sie, was Sie getan haben, welches Ergebnis Sie erwartet haben und was stattdessen passiert ist. Wenn sich das Problem wiederholen lässt, nennen Sie auch die wenigen nötigen Schritte.

03

Anmeldung und Zugriff

Wenn Sie sich bei einem AXIONA System nicht anmelden können oder Ihnen ein benötigter Zugriff fehlt, nennen Sie die betroffene Anwendung und den betroffenen Zugriff.

04

Sicherheit und Datenschutz

Wenn Sie ein Sicherheitsproblem, unberechtigten Zugriff oder ein Datenschutzproblem vermuten, kennzeichnen Sie das deutlich. Senden Sie niemals Passwörter, Anmeldecodes, API-Schlüssel oder andere Geheimnisse per E-Mail.

SUPPORT-KONTAKT

hello@axiona.systems

Schreiben Sie mir direkt per E-Mail. Senden Sie nur die Informationen, die zum Verständnis und zur Bearbeitung der Frage oder des Problems notwendig sind.

EINE HILFREICHE ERSTE NACHRICHT

Ein paar genaue Angaben helfen weiter.

Sie brauchen keinen langen Bericht. Senden Sie von den folgenden Angaben nur das, was für das konkrete Problem wirklich relevant ist.

01

Anwendung oder System

Nennen Sie den Namen des Produkts, der Anwendung oder der Seite. Wenn eine sichtbare Versionsnummer relevant ist, geben Sie sie ebenfalls an.

02

Was ist passiert?

Beschreiben Sie kurz die Aktion, das erwartete Ergebnis und das, was Sie tatsächlich beobachtet haben.

03

Umgebung

Gerät, Betriebssystem oder Browser sind nur dann nötig, wenn sie mit dem Problem zusammenhängen könnten.

04

Screenshot, wenn hilfreich

Fügen Sie ein Bild bei, wenn es das Problem schneller verständlich macht. Blenden Sie unnötige persönliche oder vertrauliche Daten aus.

DIREKTER SUPPORT

Schreiben Sie mir, wobei ich helfen kann.

Nennen Sie im Betreff den Namen der Anwendung oder des Systems. Für ein neues Projekt, ein Angebot oder eine Zusammenarbeit ist die Seite Kontakt der richtige Ausgangspunkt.
