SUPPORT

If something does not work as expected, describe it briefly.

You do not need to write a long ticket. For the first step, tell me which application or page is affected, what you did, what happened and which device you were using.

01

Where did it happen?

Include the application or page name and, where relevant, the device or browser.

02

What happened?

A short, precise description of the symptom is more useful than a long general explanation.

03

Can it be repeated?

If you know, include the few steps that make the issue appear again.

04

Screenshot

Attach an image if it helps explain the issue. Do not send unnecessary or sensitive information.
