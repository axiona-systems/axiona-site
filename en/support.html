AXIONA SUPPORT

Help with AXIONA applications and systems.

If you have a usage question, encounter a problem, cannot access something you need, or suspect a security issue, start here. Support is currently available by direct email; you do not need to prepare a technical ticket.

01

Product or usage question

If a feature, step or workflow is unclear, briefly describe what you are trying to achieve and where you are getting stuck.

02

Bug or unexpected behaviour

Tell me what you did, what you expected and what happened instead. If the problem can be repeated, include the few steps required to reproduce it.

03

Sign-in and access

If you cannot sign in to an AXIONA system or cannot access a function you need, tell me which application and which access is affected.

04

Security and privacy

If you suspect a security issue, unauthorised access or a privacy problem, flag it clearly. Never send passwords, sign-in codes, API keys or other secrets by email.

SUPPORT CONTACT

hello@axiona.systems

Send me a direct email. Include only the information needed to understand and respond to the question or issue.

AXIONA / SUPPORT

A USEFUL FIRST MESSAGE

A few precise details make support easier.

You do not need a long report. From the information below, send only what is genuinely relevant to the issue.

01

Application or system

Include the product, application or page name. If a visible version number is relevant, include that as well.

02

What happened?

Briefly describe the action, the expected result and what you actually observed.

03

Environment

Device, operating system or browser is useful only when it may be related to the problem.

04

Screenshot, if useful

Attach an image if it makes the issue easier to understand. Remove or hide unnecessary personal or confidential information.

DIRECT SUPPORT

Tell me how I can help.

Put the application or system name in the email subject. For a new project, proposal or collaboration, use the Contact page instead.
