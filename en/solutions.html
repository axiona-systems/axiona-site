04 / SOLUTIONS

The right system does not always take the same form.

The job determines the interface and technology. The solution should fit the workflow, not the other way around.

FORMS OF DELIVERY

Technology follows the job.

It may be custom business software or an internal application, automation and system integration, a document or data workflow, a client portal, an online shop, a business website — or a coordinated combination of these.

  • custom business software and internal applications
  • process and task automation
  • integration of systems and data sources

WE DO NOT START WITH A PRODUCT

The first question is not “which software should we buy?”.

I start by looking at where the work breaks down, where people repeat the same steps, where information becomes uncertain and where manual effort adds no real value. The technical form comes afterwards.

01 / MANUAL WORK

The same work has to be repeated by hand.

Copying data, renaming files, updating statuses, sending routine messages or recording the same information in several places.

Typical direction: automation · integration · internal tool
02 / SCATTERED INFORMATION

The data lives in several places and nobody sees the whole picture.

Spreadsheets, email, separate applications and handwritten notes make it difficult to know what the current state really is.

Typical direction: shared data flow · integration · internal system
03 / LOST WORKFLOW

People have to remember where each case currently stands.

If the next step, owner or deadline can only be reconstructed from email and memory, the process is fragile by design.

Typical direction: workflow · task handling · document flow
04 / CLIENT-FACING NEED

The client also needs a clear digital interface.

Login, case handling, ordering, document exchange or information delivery may require a client-facing surface as one part of the wider system.

Typical direction: client portal · online shop · web interface

ONE SOLUTION CAN HAVE SEVERAL LAYERS

The interface is only the visible part.

A useful system is more than screens. The workflow, data, rules, integrations and operational safeguards work together to create the simplicity the user eventually sees.

If a simple solution is enough, I do not build unnecessary machinery. If several layers are needed, they have to work as one system.
01

Process

What starts the work, what happens next, where a decision is made and when the case is genuinely complete?

02

Data

Which information is needed, where its authoritative source is, what must be retained and what moves elsewhere?

03

Logic

Which rules can be automated, what must be validated and which decisions should remain with people?

04

Interface

Internal application, mobile or web view, client portal, online shop or a simpler site — only what the work actually needs.

05

Operations

Access, backup, logging, updates and recovery: the system still needs to be dependable after handover.

YOU DO NOT NEED TO CHOOSE THE TECHNOLOGY

Show me where the work gets stuck.

You do not need to arrive with a technical specification. It is enough to show how the work runs today, where time is wasted, where errors appear and what you would like to see or complete more simply. The form of the solution can be derived from that.

FIRST CONVERSATION

You do not need to know whether the answer is an app, an automation or a web system.

The important part is understanding the problem and the current way of working. From there we can identify the smallest useful system that creates a real improvement.

05 / OWN PRODUCT

AXIONA Keeper

A private document assistant that does more than store files: it helps you understand what is in them, what they belong to and whether you need to do anything.

IN DEVELOPMENTiPhone + iPad · Apple App Store

Bring in the document. Keeper does most of the processing.

Keeper reads it, tries to identify what it is, pulls out important details and deadlines, works out what it may belong to and flags anything that may need action. You should not have to read every document end to end, classify it by hand and remember every deadline yourself.
