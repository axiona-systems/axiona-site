PRIVACY / CURRENT OPERATION

Data handling should be as transparent as the system itself.

This notice describes the current operation of the public axiona.systems website and direct email contact. It only states processing that follows from the website and services as they operate today.

AXIONA / PRIVACYR76
TrackingNo AXIONA-integrated analytics or advertising tracker
ContactDirect email; no website data-entry form
HostingGitHub Pages

What does the current website process?

The public site is data-minimal: there are no user accounts, no ordering or payment flow, and the current source contains no marketing or analytics tracking.

01

Responsible party and contact

Responsibility for processing connected with the website and direct enquiries: AXIONA Systems / Asztalos Zoltán. Privacy requests: hello@axiona.systems.

02

Website visits

The website is hosted on GitHub Pages. GitHub states that when a Pages site is visited, the visitor IP address is logged and stored for security purposes; GitHub may process additional technical website-usage data under its own privacy terms.

03

Email enquiries

If you email us, we process your email address, any name you provide, the message content and files you voluntarily attach. We use this information to answer the enquiry, discuss projects, provide support and, where necessary, handle related legal or security matters.

04

Retention

Email data is kept for as long as needed to handle the enquiry, document related work or meet legal obligations and establish or defend claims. Retention of hosting logs is governed by GitHub’s own policies.

05

Service providers and international processing

GitHub Pages is technically involved in serving the website. GitHub may process data in several regions, including the United States and other countries, and states that it uses appropriate transfer safeguards. The email provider is also technically involved in message delivery.

06

Cookies, profiling and automated decisions

The current AXIONA website source does not integrate analytics or advertising trackers and does not use visitor profiling. The website does not make automated decisions about visitors with legal or similarly significant effects. If this changes, the notice and, where required, the consent mechanism must be updated.

07

Your rights

Depending on applicable data-protection law, you may request information, access, correction or deletion and, where applicable, restriction, objection or data portability. Requests can be sent to hello@axiona.systems.

08

Legal framework

This notice supports transparency under applicable data-protection rules, including the Swiss Federal Act on Data Protection (FADP/DSG) where applicable and the GDPR where its territorial scope applies to the processing.

Applications and software

This page does not automatically make privacy promises for every future AXIONA application. An application may refer to this notice only when its actual data processing matches it; different processing requires a separate or supplementary application-specific notice.
