Framework of the public website

The website presents my work and provides a way to get in touch. The terms of a specific project are set out in the accepted offer, contract or other written agreement, together with any mandatory rules that apply.

Who is behind the website?

Privacy and security

Website data processing is described on the Privacy page. The security principles used when designing systems are summarised on the Security page. These public notices do not replace project-specific privacy or security requirements.

Software and applications
