# R115 visual reference

Reference direction: AXIONA Keeper public visual language.

R115 is the accepted visual baseline for the current AXIONA public site. R116 adds UX corrections but does not replace this visual direction.

Use:
- warm paper/off-white dominant;
- deep petrol as controlled product/work frame, not full-card alternation;
- restrained orange for active/control emphasis;
- acid green only for status/control labels;
- cyan only as a secondary technical accent;
- thin one-pixel borders and solid offset shadows;
- structured work surfaces and document-like rows instead of node-network diagrams;
- calm editorial hierarchy and generous negative space;
- scroll motion may repeat on re-entry but remains spatial and restrained.

Avoid:
- scanner, glow or particle effects;
- CAD/relation-map aesthetics used as brand identity;
- decorative coordinates/telemetry;
- hero pointer tilt;
- full-card active background switching;
- technical density that makes a section look like a dashboard instead of an AXIONA public page.

Important UX rule carried forward by R116: informational elements must not visually advertise clickability. Do not use action arrows, pointer cursors or link-like hover movement without an actual action.
