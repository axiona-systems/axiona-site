# R113 visual reference — AXIONA / Keeper traits

Canonical visual reference is the existing Keeper/R92 direction already shipped in this repository.

- dominant warm paper: `#f1eee6`, `#fbfaf6`
- secondary warm field: `#e5dfd3`
- deep petrol: `#0b1e25`
- sparse orange accent: `#ef6b43`
- control/status acid: `#d7ef55`
- technical cyan: `#54d4ca`
- thin one-pixel borders
- solid offset shadows, no glow language
- product panels are contained objects on calm surfaces
- dark surfaces are intentional chapters/components, not the default canvas
- typography is editorial but must stay composed and human rather than monumental/CAD-poster-like

R113 applies these traits to the R112 overview structure without changing the information architecture.
