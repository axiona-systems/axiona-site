Security

Security starts with what is not exposed.

The public website shows value and trust boundaries, not private internals. Products are designed so sensitive data, provider secrets and privileged controls do not live in public client surfaces.

Biztonság

A biztonság azzal kezdődik, amit nem teszünk ki.

A publikus weboldal értéket és bizalmi határokat mutat, nem privát belső részleteket. A termékek úgy készülnek, hogy érzékeny adat, provider titok és privilegizált vezérlés ne kerüljön publikus kliensfelületre.

Public safety commitments

No secrets in public clients
API keys, private tokens, provider secrets and admin controls do not belong in public downloadable clients.
No fake features
Visible buttons and claims must map to real behavior.
Privacy by default
Collect less. Explain clearly. Avoid unnecessary tracking and permissions.
Controlled AI
AI output is treated as a proposal unless a safe deterministic rule allows execution.
Clear support paths
Users must have practical support, privacy and contact routes.
Secure publishing
Release work includes link checks, content review and support/privacy readiness.

Nyilvános biztonsági vállalások

Nincs titok publikus kliensben
API kulcsok, privát tokenek, provider titkok és admin vezérlés nem kerülhet publikus letölthető kliensbe.
Nincs hamis funkció
Látható gomb és termékállítás valódi működéshez kell kapcsolódjon.
Privacy alapból
Kevesebb adatgyűjtés. Tiszta magyarázat. Felesleges tracking és permission kerülése.
Kontrollált AI
Az AI kimenet javaslatként kezelendő, kivéve ha biztonságos determinisztikus szabály engedi a végrehajtást.
Tiszta support útvonal
A felhasználónak legyen gyakorlati support, privacy és kapcsolat útvonal.
Biztonságos publikálás
Release előtt link check, tartalmi review és support/privacy készültség szükséges.
