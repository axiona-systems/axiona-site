# AXIONA Site Deployment Checklist

1. Upload all files from this folder to the static hosting root.
2. Keep `CNAME` if using GitHub Pages with `axiona.systems`.
3. Verify these URLs after deploy:
   - https://axiona.systems/
   - https://axiona.systems/support.html
   - https://axiona.systems/privacy.html
   - https://axiona.systems/contact.html
   - https://axiona.systems/security.html
4. Test language switch on at least one desktop and one mobile viewport.
5. Test all nav links and support/contact email buttons.
6. Confirm App Store support URL points to `/support.html`.
7. Confirm App Store privacy URL points to `/privacy.html`.

STOP if any user-facing button has no effect, any HU/EN text appears at the same time, or any contact/support route returns 404.
